# AI Agent — Talent Brief Matcher

## What it does
When a brand sends a casting brief (by email, or pasted into the app), the agent reads it, searches the talent database, and returns a ranked shortlist with reasons. This is the primary AI feature Paul wants to build first.

**Why:** No vector DB needed at current talent count (~50–200). Pass all talent profiles to Claude in one prompt alongside the brief. Simple, fast, returns explanations.

## Data model — new columns on `talents` table

These need to be added via Supabase migration:

```sql
ALTER TABLE talents
  ADD COLUMN IF NOT EXISTS city TEXT,
  ADD COLUMN IF NOT EXISTS nationality TEXT,
  ADD COLUMN IF NOT EXISTS languages TEXT[] DEFAULT '{}',
  ADD COLUMN IF NOT EXISTS height TEXT,
  ADD COLUMN IF NOT EXISTS skills TEXT[] DEFAULT '{}',
  ADD COLUMN IF NOT EXISTS exclusivity TEXT,
  ADD COLUMN IF NOT EXISTS ai_profile TEXT;
```

**Existing useful fields already on talents:** `ig_followers`, `tiktok_followers`, `category`, `talent_level`, `country`, `notes`

**Deliberately excluded for now:** measurements, rate card (too sensitive / won't be maintained)

## AI Profile field
Free-text per talent, written or auto-generated by Claude. Example:

> "Sapphire Howell is a US actress and model based in Dubai. Editorial and luxury aesthetic, comfortable with high-fashion runway and commercial campaigns. 2M+ Instagram following. Bilingual English. Known for sophisticated, aspirational imagery."

"Generate" button calls an API route that fetches the talent's full data (name, category, level, country, skills, ig_followers, past projects/brands) and sends to Claude to draft the profile. Human reviews and saves.

## Build phases

**Phase 1 — Data collection (next to build)**
1. Supabase migration: add 7 new columns to talents
2. Create `talent_skills` lookup table + seed with agreed list
3. Update talent edit form: city, nationality, languages (tag input), height, skills (multi-select from talent_skills), exclusivity (textarea), ai_profile (textarea + Generate button)
4. Add Talent Skills section to Admin → Lookups tab (same pattern as other lists)
5. API route: `POST /api/ai/generate-profile` — takes talent ID, fetches data, calls Claude, returns draft profile

**Phase 2 — Brief Matcher UI**
- New page `/talents/match` or modal
- Textarea: paste the brief
- On submit: API route fetches all talent profiles + structured data, sends to Claude with brief
- Claude returns ranked list with reasons
- Display with links to talent profiles

**Phase 3 — Email integration (later)**
- Scan inbound emails for casting briefs
- Auto-trigger matching when brief detected
- Surface suggestions in a dashboard widget
